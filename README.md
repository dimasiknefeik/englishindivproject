# Тренажёр по грамматике английского языка

Индивидуальный проект. Программа на Python + Tkinter: слева список тем,
справа — теория и тренажёр с проверкой ответов.

## Файлы проекта

```
english_grammar_app/
├── main.py              ← код программы (ничего трогать не нужно)
├── README.md             ← этот файл
└── data/
    ├── topics.json        ← ВСЯ теория и упражнения (сюда добавляешь темы)
    └── progress.json       ← создаётся автоматически, хранит статистику
```

## Как запустить

**В Thonny:** открой `main.py` → кнопка Run (зелёный треугольник) или F5.

**В VS Code:** открой папку `english_grammar_app`, открой `main.py`,
запусти (Run Python File). Библиотек ставить не нужно — используется
только стандартный `tkinter`, который идёт вместе с Python.

Если Tkinter вдруг не найден — переустанови Python с сайта python.org
и на шаге установки поставь галочку **tcl/tk and IDLE**.

## Группы тем и вкладка «Тест»

**Группы.** Темы в списке слева собираются в группы по полю `category`.
Порядок групп такой же, как порядок, в котором они впервые встречаются
в `topics.json`. Группу можно свернуть и развернуть двойным щелчком.

**Тест.** На вкладке «Тест» программа берёт 10-15 случайных вопросов
(число выбираешь перед стартом) из упражнений **всех тем** и старается
брать вопросы из разных тем. Во время теста подсказок нет. В конце
показываются оценка, процент, темы для повторения и разбор каждого вопроса.
Результаты сохраняются в `data/test_results.json`.

Вопросы для теста — это те же `exercises` из `topics.json`. Чтобы тест
был разнообразным, добавляй в каждую тему хотя бы 2-3 упражнения.

**Шкала оценок** лежит в начале `main.py`, её можно поменять:

```python
GRADE_SCALE = [(85, 5), (65, 4), (45, 3)]   # (мин. % правильных, оценка)
GRADE_FAIL = 2                              # если процент ниже всех порогов
TEST_MIN_QUESTIONS = 10
TEST_MAX_QUESTIONS = 15
```

## Как добавить новую тему из тетради

Открой `data/topics.json` в любом текстовом редакторе (подойдёт и Thonny,
и блокнот, и VS Code). Это обычный текстовый файл в формате JSON — список
тем в квадратных скобках `[ ]`, каждая тема — в фигурных скобках `{ }`,
темы разделены запятой.

Скопируй один блок-пример ниже, вставь его **перед закрывающей `]`**
в конце файла (после последней темы, не забудь поставить запятую `,`
после `}` предыдущей темы) и заполни своими данными.

```json
{
  "id": "future_simple",
  "title": "Future Simple",
  "category": "Времена",
  "rule": "Здесь своими словами объясни правило. Если правило длинное — можно разбить на пару абзацев через \n\n (это перенос строки).",
  "formula": "will + V1",
  "examples": [
    "I will call you tomorrow.",
    "It will rain soon."
  ],
  "markers": ["tomorrow", "next week", "soon", "in a year"],
  "notes": [
    "Любые дополнительные заметки или исключения из тетради."
  ],
  "exercises": [
    {
      "question": "I ___ (call) you tomorrow.",
      "answers": ["will call"],
      "explanation": "Future Simple: will + V1."
    },
    {
      "question": "It ___ (rain) soon.",
      "answers": ["will rain"],
      "explanation": "Future Simple: will + V1."
    }
  ]
}
```

### Что означает каждое поле

| Поле         | Обязательно? | Что это |
|--------------|:---:|---------|
| `id`         | да  | Короткое уникальное имя темы латиницей, без пробелов (`future_simple`). Используется только программой, не показывается пользователю. Не должно повторяться у двух тем. |
| `title`      | да  | Название темы, которое видно в списке слева. |
| `category`   | желательно | Название группы, в которую попадёт тема в списке слева (например, `"Времена"`). Пишется одинаково у всех тем группы. Без этого поля тема окажется в группе «Другое». |
| `rule`       | да  | Текст правила. `\n\n` — пустая строка между абзацами. |
| `formula`    | нет | Короткая формула вида `have/has + V3`. Если её нет — просто убери эту строку целиком. |
| `examples`   | нет | Список примеров-предложений. |
| `markers`    | нет | Список слов-маркеров через запятую. |
| `notes`      | нет | Список дополнительных заметок, исключений. |
| `exercises`  | нет | Список упражнений (см. ниже). Без них теория покажется, но тренажёр скажет «нет упражнений». |

Необязательные поля можно просто не писать — программа их пропустит
и не сломается.

### Упражнения

Каждое упражнение — это:

```json
{
  "question": "текст вопроса с пропуском ___",
  "answers": ["ожидаемый ответ", "второй вариант, если допустим"],
  "explanation": "что подсказать, если ответ неверный"
}
```

- `answers` — всегда список, даже если правильный ответ один
  (`["goes"]`). Если подходит несколько формулировок — перечисли все
  (`["don't like", "do not like"]`).
- Проверка не различает заглавные/строчные буквы и лишние пробелы
  по краям, но требует точного совпадения остального текста —
  не пиши в вопросе два варианта пропуска сразу, лучше сделать два
  отдельных упражнения.

### Проверка файла после правок

Запусти `check_topics.py` (в Thonny: открыть файл → F5). Он проверит
`data/topics.json` и напишет по-русски, что не так и в какой строке:
пропущенная запятая, дубль `id`, `answers` не списком и т.п.
Делай это каждый раз перед запуском `main.py` и перед сборкой `.exe`.

### Частые ошибки при редактировании JSON

- Забыли запятую между темами или между упражнениями.
- Лишняя запятая после последнего элемента списка (перед `]` или `}`
  запятой быть не должно).
- Не закрыли кавычки или скобки.

Если после редактирования программа не запускается или ругается на
`topics.json` — проверь файл на сайте **jsonlint.com** (вставь туда
содержимое файла, он покажет, где именно ошибка).

## Как собрать .exe (чтобы показать на защите без Python)

Подробная пошаговая инструкция — в чате, где ты это спрашивал. Коротко:

```
pip install pyinstaller
pyinstaller --onefile --windowed --name GrammarTrainer --add-data "data;data" main.py
```

Готовый `GrammarTrainer.exe` появится в папке `dist`. Папку `data` копировать
руками не нужно — `topics.json` уже встроен внутрь exe (это и делает флаг
`--add-data`), а при первом ответе в тренажёре программа сама создаст рядом
с exe новую папку `data` с файлом `progress.json` для сохранения прогресса.
Это проверено: exe действительно работает сам по себе, без main.py и без
исходной папки data рядом.

  темам, самые слабые темы.
